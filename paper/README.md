# The paper

**Historical Confidentiality for Encrypted Agent Memory: Dual-Epoch Security and the Channels That
Defeat It**

## Building

From `python/`, with the results in `python/eval/results/`:

```bash
python -m eval.exp2.make_tables
python -m eval.exp2.numbers
python -m eval.exp2.make_figures
python -m eval.figures.fig2_threat_model
python -m eval.build_paper
```

`build_paper` runs `pdflatex` and `bibtex` on `main.tex` and then `supplement.tex`. Build the main
paper first: the supplement reads `main.aux` (package `xr`) so that its references resolve to the
main paper's numbering. `python -m eval.make_docx` exports Word versions of both, laid out like
the PDFs (it needs Microsoft Word for its final pass and skips that pass otherwise).

The class is IEEEtran (Computer Society journal) with the `IEEEtran` bibliography style.

## Generated inputs

Everything in `tables/` is generated: `numbers.tex` holds every number the prose quotes, and the
other files are the tables. Do not edit them by hand; rerun the generators above. Figures in
`figures/` are generated by `python -m eval.exp2.make_figures` and
`python -m eval.figures.fig2_threat_model`. `repo.tex` holds the artifact
repository URL quoted in the Availability section.
