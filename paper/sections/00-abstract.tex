AI agents write their own long-term memory to an encrypted local store and retrieve it by semantic
search. We study an adversary that obtains the storage layer partway through such a
store's life, through a synchronized backup or repeated disk imaging, observes later activity, and
can steer the agent's inputs, but holds only stored state for records written earlier. We show that
historical confidentiality, the safety of data written before the compromise, is a distinct
system-level property that encryption, snapshot security and history independence do not provide.
For stores that place records by content, topic labels the adversary induces through new writes
transfer to earlier records; a transfer lemma names the precondition, that the layout disclose which
partition holds an earlier record, and a deployed store, pgvector under an encrypted filesystem,
meets it. A store that seals that channel is reached by three others: retained file versions,
capacity refusals, and derived writes, where an agent that deduplicates turns the occurrence of a
write into a membership oracle, which we confirm in the unmodified mem0 library. We formalize
dual-epoch security as an adaptive, leakage-parameterized game, prove sufficient conditions covering
overflow, separate it from breach resistance and history independence, and give a reactive variant
whose composition theorem covers the self-writing agent. A store with content-independent placement,
in-memory search and a clocked write-only-oblivious flush closes every channel against a write
observer, at kilobytes per flush, and extends past the memory limit with its writes still hidden.
A released artifact reproduces every number.
