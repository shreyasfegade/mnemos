\section{Conclusion}
\label{sec:conclusion}

Historical confidentiality, the protection of what an agent remembered before its storage was
compromised, is a property of its own: encryption, snapshot security and history independence do
not deliver it. For content-placed indexes, induced writes label partitions with topics, and where
the layout discloses which partition holds each stored record those labels apply to records written
before the compromise; the transfer lemma makes that condition precise, and a deployed store,
pgvector under a stacked encrypted file system, meets it.

Fixed-size sealed regions close the snapshot channel, overflow included, and three channels reach
the earlier cohort anyway: retained versions, refusals, and the agent's own operations, down to the
occurrence of a write, which makes deduplication a membership oracle in a widely used library
whenever its model writes conditionally. Against
a self-writing agent a store is secure exactly when what it reveals is independent of what the agent
does. A store whose disk behaviour is a function of the clock alone meets that condition: placement independent of content, search in locked memory over a logical index, and a
clocked write-only-oblivious sweep, at \REtwentyoneSweepKiB~KiB per flush. Keeping headers on disk
extends it past the memory limit with its writes still invisible to a write observer.

Two problems remain open: a read observer of a store too large to keep resident is defeated only
by oblivious search, whose cost against these designs is unmeasured, and version retention at a
provider is beyond the reach of the storage layer.
